## Major work landed

### Cross-project — shared `C:\dev\mtg_cards\` data folder

- New folder at `C:\dev\mtg_cards\` (out-of-repo, not gitignored from
  any project). Holds:
  - `bulk_data/default_cards.json` — Scryfall bulk dump (~512MB,
    ~32,000 cards) with `_meta.json` for cache-freshness checks.
  - `oracle_snapshots/` — per-card JSON snapshots, populated from the
    bulk dump. Refreshable on demand for guaranteed-current oracle text.
  - `images/` — empty, reserved for future card-image fetcher (FP-008
    in commander_builder/FUTURE_PLANS.md).
  - `rules/MagicCompRules_2026-02-27.txt` — Wizards' Comprehensive Rules.
- All three projects honor `MTG_CARDS_DIR` env var with graceful
  fallback to per-project `.cache/`. **Zero coupling** between
  projects' code; they just happen to read/write the same disk
  location.
- Detected and re-primed a truncated 180MB bulk file mid-session.

### forge_py — P1, P2, P4 of ROADMAP.md done

- **P1 (live card-text API)** — `forge_py.cards` module:
  `refresh()`, `get()`, `is_fresh()`, `get_oracle_text()` with
  `_fetched_at` timestamps and 7-day default freshness window.
  CLI: `forge-py refresh / show / prime`.
- **P2 (bulk-data in-memory index)** — `forge_py.bulk_index` module:
  process-singleton 32k-card map, lazy-loaded. Wired into
  `card_tagger._scryfall_lookup` so cold-cache deck tagging hits RAM
  instead of HTTP. Test-isolation gate prevents 180MB load during unit
  tests.
- **P4 (color-aware mana modeling)** — `forge_py.mana` module:
  `parse_mana_cost`, `produced_colors`, `can_cast`, `spend`. Handles
  WUBRG, hybrid (`{W/U}`), Phyrexian (`{W/P}`), colorless-`{C}`,
  generic-`{N}`, X, snow. New `color_screw_rate` metric in
  goldfish reports — fraction of opening hands with right number of
  lands but wrong colors. **Validated on real decks**: 11.5%
  (3-color Hakbal), 22.5% (4-color Mothy), 39.5% (5-color First
  Sliver) — strictly monotonic with color count.
